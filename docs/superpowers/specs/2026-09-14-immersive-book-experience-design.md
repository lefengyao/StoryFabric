# StoryFabric 沉浸式书本展示体验设计

日期：2026-09-14

## 背景

`StoryFabric-web` 是一组静态 HTML/CSS/原生 JavaScript 产品展示页，当前包含产品首页、写作台、故事世界、智能体、开源和下载页。现有页面已经具备完整的标题、介绍、产品演示、版本清单、下载按钮、导航和交互逻辑。

本次改造的主题是“图书馆中创作的一本书”：用户从书架取书，打开书阅读产品内容，在页面间翻阅，最后在下载页合书并归回书架。用户已经确认以下视觉方向：

- 采用书本作为首屏主舞台，而不是单张纸张。
- 书页放大到首屏主要视觉区域，左右页有足够空间承载首页首屏内容。
- 书本使用精装封面、金色书脊、厚实页芯、页边切面和动态阴影，必须具有明显重量感。
- 图书馆背景、暖光和桌面场景作为氛围层，不能抢过书页内容。

## 目标

1. 在不删除、不改写、不改变现有按钮行为和页面功能的前提下，为全站增加书本视觉承载层。
2. 首页呈现“悬浮之书”，原有标题、Slogan、介绍、Logo 和首屏入口写在书页上。
3. 站内页面跳转呈现以书脊为旋转轴的翻页转场，支持点击导航、前进和后退。
4. 下载页完成“合书 → 归架 → 镜头拉远 → 学生介绍 → 下载内容淡入”的叙事链条。
5. 使用 CSS 3D 和 GSAP 优先实现流畅动效，移动端、低性能设备和减少动态效果设置下提供稳定降级。
6. 保持页面语义化 HTML、键盘导航、屏幕阅读器可读和普通链接回退能力。

## 非目标

- 不重写现有页面文案、产品数据、版本清单、按钮文本或业务交互。
- 不将静态多页面站点强行改造成完整 SPA，不通过 AJAX 重新拼接已有页面内容。
- 第一版不接入 Three.js、WebGL 场景或真实 3D 角色系统；Three.js 作为未来可替换的场景增强适配器。
- 不引入登录、在线协作、GitHub API 或新的后端服务。
- 不承诺真实学生动作捕捉。没有正式立绘或模型时，使用明确标注的分层 SVG 占位角色。

## 现有约束与决定

### 技术现状

- 当前站点没有构建工具、npm 前端依赖或 Three.js/GSAP 依赖。
- 页面通过 `server.mjs` 提供静态文件服务。
- 页面行为集中在 `assets/app.js`，版本清单由 `downloads/versions.json` 和 `assets/versions.js` 提供。
- 当前已有 Logo SVG，尚无图书馆背景、书本模型、学生立绘和 3D 模型资源。

### 采用的实现路径

第一版采用“CSS 3D 书本 + GSAP 时间线 + HTML 场景层”的渐进增强方案：

- CSS 负责书本几何体、封面、书脊、页芯、页面弯曲和响应式布局。
- GSAP 负责时间线、缓动、交错入场、鼠标视差和转场状态编排。
- HTML/CSS 负责图书馆背景、台灯、书桌、电脑和学生占位角色。
- 现有页面内容仍保存在原来的语义 DOM 中，只增加场景容器和数据属性。
- GSAP 使用本地静态文件，避免 CDN 不可用导致展示页失去动效。

## 架构

### 文件职责

计划新增或修改以下文件：

```text
StoryFabric-web/
├─ assets/
│  ├─ vendor/gsap.min.js                 本地 GSAP 运行时
│  └─ immersive/
│     ├─ book-experience.css             书本、场景、降级样式
│     ├─ book-experience.js              共享入口与生命周期
│     ├─ book-scene.js                   书本模型、浮动和视差
│     ├─ route-transition.js             导航、History、翻页转场
│     ├─ download-scene.js               合书、归架、学生和下载页场景
│     ├─ library-background.webp         图书馆背景占位资源
│     └─ student-placeholder.svg         分层学生占位资源
├─ assets/app.js                          保留现有逻辑，接入共享入口
├─ assets/styles.css                      保留现有样式，补充场景兼容规则
└─ *.html                                 只增加场景容器、脚本和必要数据属性
```

若实际实现可以将三个 JS 文件合并为一个共享文件，也必须保留三个职责边界：书本场景、路由转场、下载场景不能互相依赖内部细节。

### DOM 分层

每个页面采用以下层级，原有 `main` 内容保持原顺序：

```html
<body data-page="home" data-book-experience>
  <div class="book-scene-layer" aria-hidden="true"></div>
  <div class="book-content-layer">
    <main id="main">
      <!-- 现有页面内容，不删除、不改写、不换序 -->
    </main>
  </div>
</body>
```

场景层只承载装饰和动效，不承载必须阅读的文字。原页面标题、段落、表单、下载按钮和交互控件继续在语义内容层中，避免动画失败时页面不可用。

首页首屏的主内容通过 CSS 让现有首屏区域成为书页表面；下方已有 section 仍按原顺序成为连续章节。内页沿用同一书本外壳，但不复制业务内容。

### 书本模型

书本由以下 CSS 3D 部件组成：

- `book-cover-front`：蓝色精装前封面，带金色产品标记。
- `book-cover-back`：后封面和底部厚度。
- `book-spine`：金色书脊，作为翻页旋转轴。
- `book-page-block`：多层页芯和右侧切边。
- `book-page-left` / `book-page-right`：承载当前内容的左右页面。
- `book-shadow`：根据悬浮高度改变 scale、opacity 和 blur。

翻页不使用单个平面直接翻转，而是将页面分成多个可控片段，通过相邻片段的 `rotateY` 和 `translateZ` 形成弧面。这样可以在不引入 WebGL 的情况下模拟纸张弯曲。

## 页面行为

### 首页：悬浮之书

- 图书馆背景使用暖色木质书架、局部灯光和轻微景深。
- 精装书斜置约 15°～25°，书页放大为首屏主要视觉区域。
- 书本持续上下浮动 5～10px，周期 4～6 秒。
- 书本下方阴影随高度同步缩放和透明度变化。
- 鼠标移动时书本产生约 ±5° 的轻微 3D 视差。
- 页面入场时先显示封面和书本体积，再打开页面并让原首页首屏内容分批出现。
- 点击“开始探索”或向下滚动时，书本轻微放大并翻向第一章。

### 普通展示页

写作台、故事世界、智能体和开源页继续保留全部原内容。跳转时只改变书本承载层、页面可见状态和内容入场方式，不修改页面自身交互逻辑。

页面内已有的 tab、按钮、复制操作、演示状态、版本渲染和表单行为继续由原有脚本负责；沉浸式模块只负责导航转场锁定和动画生命周期。

### 下载页：合书归架

下载页的原有内容层放在场景下方或右侧的半透明内容面板中，内容完整保留：

- 下载按钮
- 最新版本和发布描述
- 系统要求
- 历史版本和更新信息

场景层包含书架、书桌、台灯、电脑、稿纸、钢笔、咖啡和学生占位角色。学生的占位资源必须在代码注释和资源清单中标明，后续可以替换为正式分层立绘或 3D 模型。

## 导航与 History API

### 正常站内链接

站内链接仍保留真实 `href`。转场协调器只拦截同源、非下载文件、非新窗口的页面链接：

1. 判断目标页面和当前页面。
2. 写入 `sessionStorage`：来源页、目标页、方向、转场类型和时间戳。
3. 使用 `history.pushState` 写入目标路由状态。
4. 禁用重复点击，并播放离场翻页或下载页合书动画。
5. 动画完成后使用原页面导航加载目标文档；若动画脚本、资源或 GSAP 失败，则立即执行原始链接。
6. 目标文档读取 `sessionStorage`，播放对应的开页和内容入场动画。

### 前进与后退

- `popstate` 负责处理当前文档内的 History 状态变化。
- `pageshow` 和 `performance` 导航类型负责处理浏览器真正加载前一页或后一页的情况。
- 页面顺序固定为：首页、写作台、故事世界、智能体、开源、下载；返回时根据来源和目标索引确定从左向右还是从右向左。
- 如果无法确定来源，默认使用简洁淡入，不阻塞页面内容。
- 前进/后退期间继续锁定重复触发，动画结束后恢复键盘和鼠标操作。

## 动效时间轴

### 首页首次加载：1.8 秒

| 阶段 | 时间 | 动作 | GSAP 属性 |
|---|---:|---|---|
| 背景出现 | 0～0.4s | 图书馆从虚化中出现 | opacity、filter |
| 书本浮现 | 0.3～1.2s | 封面、书脊、页芯和阴影建立体积 | y、rotateX、rotateY、opacity |
| 开页 | 0.9～1.5s | 左右页面打开到阅读角度 | rotateY、transformOrigin |
| 内容入场 | 1.2～1.8s | 标题、介绍、入口依次上移淡入 | y、opacity |
| 常态 | 1.8s 后 | 书本持续轻微悬浮和页边颤动 | y、rotateZ |

### 普通翻页：1.6～2.0 秒

| 阶段 | 时间 | 动作 |
|---|---:|---|
| 翘页提示 | 0～0.25s | 右下角页面翘起，阴影和褶皱加强 |
| 页面弯曲 | 0.25～0.7s | 页面片段依次产生弧度 |
| 翻页执行 | 0.45～1.15s | 页面以书脊为轴从右向左翻转 |
| 新页出现 | 1.1～1.35s | 新页面稳定，旧内容完全隐藏 |
| 内容入场 | 1.35～1.8s | 目标页内容分组上移淡入，组间约 100ms |
| 稳定 | 1.8～2.0s | 恢复可操作状态 |

返回时将旋转方向反转。多个页面跳转最多连续翻 1～2 页，总时长不超过 2.5 秒。

### 下载页归架：3.6 秒

| 阶段 | 时间 | 动作 |
|---|---:|---|
| 合书 | 0～1.0s | 左右页闭合，露出精装封面 |
| 飞向书架 | 1.0～1.8s | 书本沿弧线移动到预留空位 |
| 归位反馈 | 1.5～1.9s | 空位高亮，相邻书本轻微晃动 |
| 镜头拉远 | 1.8～3.0s | 视野从书本扩展到图书馆一角 |
| 学生动作 | 2.4～3.2s | 呼吸、眨眼、抬手并朝内容区域示意 |
| 内容淡入 | 3.0～3.6s | 下载内容层显示并恢复操作 |

### 离开下载页：不超过 2 秒

镜头推近 → 书本从书架抽出 → 封面打开 → 反向翻页 → 目标页面内容淡入。

## 资源规范

### 第一版占位资源

| 资源 | 路径 | 状态 | 替换要求 |
|---|---|---|---|
| 图书馆背景 | `assets/immersive/library-background.webp` | 占位 | 2x WebP，暖色木质书架，单文件不超过 500KB |
| 书架层 | CSS/HTML | 占位 | 后续可替换为 WebP 或 Three.js 场景 |
| 学生角色 | `assets/immersive/student-placeholder.svg` | 占位 | 分层头部、身体、手臂和手掌 |
| 书本模型 | CSS 3D | 第一版实现 | 保留封面、书脊、页芯和切边结构 |
| 台灯与咖啡热气 | CSS | 第一版实现 | 仅使用 transform、opacity 和 box-shadow |

没有正式美术资源时，页面必须显示风格协调的占位版本，并在资源清单和代码注释中写明替换位置。不能把占位学生描述成最终角色资产。

## 性能、响应式和可访问性

### 性能

- 动画优先使用 `transform`、`opacity`、`filter`，避免连续改变布局尺寸。
- 进入视口前懒加载图书馆背景和下载页场景资源。
- 页面转场期间避免重复创建大量 DOM 节点。
- 书本页面片段数量控制在可观察的最小范围，先满足自然弯曲再增加细节。
- 通过浏览器性能面板观察动画帧率，目标中端设备不低于 45fps。

### 降级

检测 `prefers-reduced-motion: reduce`、低 `deviceMemory`、低 `hardwareConcurrency` 和 WebGL 不可用状态：

- 关闭连续悬浮、鼠标视差、纸张颤动和学生复杂动作。
- 普通翻页改为 300～500ms 淡入淡出。
- 下载页改为合书后直接淡入图书馆内容层。
- 所有内容、按钮、导航和版本数据仍立即可读可用。

### 响应式

- 桌面端显示完整书架、景深、书本厚度和远景场景。
- 平板端减少背景层，书本仍保持主要视觉区域。
- 移动端使用简化 CSS 2D/3D 书本，保留核心翻页；内容层改为单列，按钮保持可点击尺寸。
- 禁止页面横向溢出，导航继续使用现有移动菜单。

### 可访问性

- 场景装饰设置 `aria-hidden="true"`。
- 原有标题层级、链接、按钮和表单保留在语义 DOM 中。
- 转场锁定期间不移除焦点元素；动画结束后焦点仍能继续移动。
- 不能只用颜色表达可操作状态。
- 动画失败、脚本禁用或减少动态效果时，页面仍可正常阅读和跳转。

## 验证标准

### 内容和功能零回归

- 六个页面的原有标题、段落、Logo、按钮、链接、演示控件、下载逻辑和版本描述全部存在。
- 现有 `.qa` 测试继续通过。
- 对改造前后的主要语义 DOM 做文本和链接快照对比，新增的只允许是场景包装和必要的数据属性。

### 动效行为

- 首页入场完成后书本具有明显封面、书脊、页芯和阴影厚度。
- 鼠标视差幅度受限，不造成页面内容抖动。
- 普通导航只触发一次翻页，目标页面没有白屏闪烁。
- 前进和后退方向符合页面顺序；无法判断时使用淡入兜底。
- 下载页完整展示合书、归架、拉远、学生手势和内容淡入阶段。
- 离开下载页能在 2 秒内回到普通翻页路径。

### 降级和性能

- `prefers-reduced-motion` 下不播放大型连续动效，内容立即可用。
- 移动端无明显横向溢出。
- GSAP 或场景资源加载失败时，原链接和页面逻辑仍能工作。
- 中端设备实测帧率目标不低于 45fps；如达不到，优先减少背景层、页面片段和滤镜数量。

## 实施分期

1. 建立改造前的页面内容快照和导航回归测试。
2. 接入本地 GSAP、书本 DOM 结构、厚重书本 CSS 和首页入场动画。
3. 添加共享导航协调器，完成普通翻页、点击锁定和普通链接回退。
4. 加入 History API、前进后退和页面入场状态恢复。
5. 完成下载页合书、归架、图书馆远景和学生占位动画。
6. 加入移动端、低性能和 `prefers-reduced-motion` 降级。
7. 运行静态 QA、服务器路由检查、浏览器交互检查和性能检查。

每个阶段都必须先验证原有功能，再继续增加视觉层；如果大型场景影响内容可读性或性能，优先保留书本和翻页核心体验。
