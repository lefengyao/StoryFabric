# 设定横向树状图与图片导出设计

## 目标

在“设定”页面增加一个图表视图，将用户选中的设定及其后代按明确的父子关系排列为横向树状图，并能把当前子树导出为 PNG 图片。现有列表、Markdown 编辑和设定文件格式继续可用；旧设定无需迁移即可作为独立根节点显示。

## 方案

### 数据模型

`SettingDoc` 增加可选字段 `parentId?: string`。空值表示根节点。该字段进入设定 Markdown 的 front matter，因此桌面端、Android 端和 HTTP 服务端都沿用现有 `listSettings`、`getSetting`、`saveSetting` API，不新增 RPC。

加载旧文件时缺少 `parentId` 视为根节点。加载时只接受非空字符串；非法值按根节点处理。保存时拒绝把设定指向自己或指向自己的后代，避免创建循环。历史文件中已经存在的孤儿引用不阻塞页面：图表把它提升为根节点，并给节点显示孤儿提示，便于用户修复。

删除父级设定不自动改写子级文件。子级保留原 `parentId`，删除后会作为孤儿根节点显示；这样恢复父级时关系不会丢失。

### 页面交互

设定页面顶部增加“列表 / 图表”切换。列表模式保持当前行为。图表模式提供设定选择器，默认选择一个安全根节点，不把多个根节点合并到同一画布；用户也可以点击图中节点，将该节点切换为当前树根并查看它的后代。节点显示标题、分类、标签数量；通过独立的“打开设定”操作进入正文详情。

图表使用现有 `@xyflow/react`。布局采用确定性的横向树：根节点在最左侧，子节点向右展开；同一父级的子节点按标题、再按 id 排序。提供缩放、拖动、适应画布和空状态。拖动只影响当前查看，不把临时坐标写入设定正文或人物关系布局文件；刷新后重新使用确定性布局，确保不同平台一致。

编辑模式新增“父级设定”下拉框，选项排除当前节点及其后代。保存前在 UI 和实体层都校验，避免绕过 UI 的调用写入循环关系。

### 图片导出

图表工具栏提供“导出图片”。导出内容不依赖当前可视区域，而是根据当前选中子树的节点和边生成独立 SVG，再在浏览器 Canvas 中栅格化为 PNG。节点尺寸、字体、边距和背景色由导出渲染器固定计算，避免 React Flow 的 CSS 或 foreignObject 在 Android 与桌面端产生差异。

PNG 使用现有章节长图的分享链路：桌面端和普通浏览器下载文件，Android 通过 Capacitor Cache 与系统分享/保存面板。文件名使用工作区名和“设定图谱”，空树导出按钮禁用；生成失败显示可读错误，不影响当前图表。

### 兼容性与数据流

实体层负责 `parentId` 的读取、写入和循环校验；渲染层的纯函数负责把 `SettingMeta[]` 转成树节点、边和 SVG。工作区归档无需新增文件，因为关系保存在每个设定的 front matter 中。旧版本打开新工作区时会忽略未知字段但不会删除它们；本版本保存设定时显式保留 `parentId`。

## 组件边界

- `shared/types.ts`：声明 `SettingDoc.parentId`。
- `core/workspace/entityStore.ts`：规范化 `parentId`、校验父级和循环、序列化 front matter。
- `renderer/src/lib/settingsTree.ts`：纯函数生成层级、布局、孤儿/循环保护和稳定排序。
- `renderer/src/lib/settingsTreeImage.ts`：从布局生成 SVG，并把 SVG 转 PNG 文件。
- `renderer/src/pages/settingsDocs/SettingsDocsPage.tsx`：视图切换、父级选择和图表入口。
- `renderer/src/pages/settingsDocs/SettingsTreeView.tsx`：当前树根选择、子树画布、节点切换和导出状态。
- 现有 `chapterLongImage` 分享逻辑：抽取通用 PNG 分享函数，保持桌面、Web、Android 三端行为一致。

## 错误处理

- 无父级目标、当前节点或后代目标：保存返回明确的父级关系错误，原文件不变。
- 孤儿或历史循环：图表构建终止异常边并把受影响节点提升到根层，同时显示提示；不会卡死或递归溢出。
- SVG/Canvas 不支持或导出失败：保留图表，显示错误提示。
- 旧设定没有 `parentId` 时：每条设定作为独立根节点；选择器保证一次只查看和导出一棵树，不能根据普通正文引用自动推断父子关系。
- 设定正文加载失败：列表仍可显示元数据；图表只依赖元数据，不因单条正文失败而不可用。

## 测试计划

- 实体层：父级字段保存/加载、旧文件根节点、自己/后代循环拒绝、孤儿加载。
- 树逻辑：稳定排序、横向层级坐标、孤儿和循环保护、空树。
- SVG 导出：节点和边完整出现、特殊字符转义、空树和尺寸计算。
- 页面：列表/图表切换、父级选择排除后代、导出按钮错误状态。
- 运行现有相关 Vitest 测试、全量 TypeScript 检查和构建。

## 非目标

本次不从 Markdown 标题或自然语言自动推断父子关系，不新增设定之间的多对多引用图，不保存手动拖动坐标，也不改变现有列表排序和正文编辑器行为。
