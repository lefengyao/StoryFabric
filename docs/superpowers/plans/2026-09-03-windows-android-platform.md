# Windows + Android 多端发行实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不破坏现有 Windows Electron 版本的前提下，把 StoryFabric 演进为可复用共享核心、Windows Electron 壳和 Android Capacitor 壳的双端应用。

**Architecture:** 将领域类型、Markdown/JSON 序列化、工作区实体服务、会话模型和 LLM/Agent 协议逐步迁移到无 Electron/Node 依赖的共享核心。Windows 继续通过 Electron 主进程访问本地文件和系统密钥；Android 通过 Capacitor Filesystem、Preferences/Keystore 访问应用目录和密钥。渲染层只依赖统一的 `StoryFabricApi`，由平台启动代码注入 Electron 或 Android 实现。

**Tech Stack:** React 19, TypeScript, Zustand, Electron, electron-builder, Capacitor 7, Capacitor Filesystem, Capacitor Preferences, gray-matter, Vitest。

```ts
it('provides portable file operations', async () => {
  const store = new MemoryFileStore()
  await store.ensureDir('characters')
  await store.writeText('characters/林晚.md', 'content')
  expect(await store.readText('characters/林晚.md')).toBe('content')
  expect(await store.listFiles('characters', '.md')).toEqual(['林晚.md'])
  await store.remove('characters/林晚.md')
  expect(await store.readText('characters/林晚.md')).toBeNull()
})
```

- [ ] **Step 3: 实现契约与 Node 适配器**

`FileStore` 固定使用相对路径和 `/` 分隔符，避免把 `path.join` 泄漏到共享核心；Node 适配器负责将相对路径解析到工作区根目录，并拒绝 `..` 穿越。

```ts
export interface FileStore {
  exists(path: string): Promise<boolean>
  ensureDir(path: string): Promise<void>
  readText(path: string): Promise<string | null>
  writeText(path: string, text: string): Promise<void>
  remove(path: string): Promise<void>
  listFiles(dir: string, extension?: string): Promise<string[]>
}
```

## 发布边界

第一版双端采用“各自本地工作区 + 手动导入/导出”，不承诺跨设备自动同步。云同步应作为独立后续项目，包含账号、版本号、冲突合并和服务端存储，不与本次平台解耦混在一起。
