# StoryFabric 最小项目示例

这是一个按 StoryFabric 格式 5 工作区规范准备的最小可打开项目，用于 Windows 端冒烟测试。

覆盖内容：

- 第一卷：潮汐
- 正文箱章节 `潮汐塔的门`
- 草稿箱章节 `未定稿`
- 总纲和第一章章纲
- 一个主要角色和一个次要角色
- 背景设定和其他设定
- 一个事件、一条人物关系和一个便签
- 空回收站索引

在应用中选择“打开工作区”，选择当前目录即可：

```text
examples/minimal-workspace
```

建议冒烟顺序：打开项目 → 查看章节树 → 打开正文章和草稿章 → 查看总纲/章纲、人物、设定和便签 → 搜索“星门” → 导出工作区 → 再导入为副本。

该目录不包含 API Key、会话内容或构建产物。
